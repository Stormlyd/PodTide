# PodTide

PodTide 是一款面向 Android 的开源 AirPods 伴侣应用，提供电量显示、连接辅助和耳机控制。应用基于 [CAPod](https://github.com/d4rken-org/capod)，并参考 [LibrePods](https://github.com/librepods-org/librepods) 的协议与功能实现。

## 系统适配与必开权限指南（重要）

为了保证耳机广播扫描、开盖弹窗、自动连接及后台监测在各品牌手机上稳定运行，**请在首次使用时完成以下权限与系统设置**：

### 1. 所有手机通用的必开权限与设置

- **位置权限设为“始终允许”+“精确位置”，并开启系统 GPS 总开关（所有手机必须）**：
  - Android 系统底层将 AirPods 电量与盒盖广播归类为蓝牙信标数据。
  - 请务必将 PodTide 的位置权限设为 **“始终允许”**（若仅选“使用期间允许”，退到后台后将无法扫描广播）并开启 **“精确位置”**；同时保持手机下拉控制中心的 **“位置信息（GPS）”总开关处于开启状态**，否则系统底层会直接拦截全部耳机广播。
- **附近设备（蓝牙）与通知权限**：用于扫描连接耳机及维持后台监测前台服务。
- **电话权限（可选，仅头部手势控制来电需要）**：若需使用点头接听、摇头拒接来电功能，需授予读取通话状态与接听电话权限。
- **悬浮窗权限（显示在其他应用的上层）**：所有系统通用，开启后才能在桌面或其他应用上方显示底部开盖与连接状态弹窗。
- **后台弹出界面与锁屏显示权限（小米 / vivo / OPPO / 荣耀 / 华为必查）**：国产定制系统在标准“悬浮窗”之外，通常在 `应用详情` → `权限管理（或其他权限）` 中还单独设有 **“后台弹出界面”** 和 **“锁屏显示”** 权限（默认多为拒绝），请一并设为 **“允许”**，否则后台弹窗或点击弹窗跳转可能被拦截。
- **应用自启动权限**：所有系统均需在应用设置或手机管家中开启 PodTide 的**自启动**，确保服务被回收或重启手机后能自动恢复监测。
- **后台多任务卡片锁定**：打开系统“最近任务（多任务）”界面，找到 PodTide 卡片（下拉卡片或点击卡片右上角菜单）点击 **“锁定”**，防止被系统内存清理或“一键加速”杀掉进程。
- **忽略电池优化（加入电池优化白名单）**：除下方的后台耗电设置外，可在系统 `设置` 中搜索 **“电池优化”** → 切换显示 **“所有应用”** → 找到 `PodTide` → 设为 **“不优化 / 不允许优化”**。
- **Android 13+“受限设置”解锁（若权限灰色无法开启）**：通过安装包直接安装时，若部分权限提示“受限设置”，请进入 `设置` → `应用管理` → `PodTide` → 点击右上角 `⋮` 菜单 → 选择 **“允许受限设置”**。

### 2. 各品牌手机“完全允许后台活动”设置路径

不同品牌系统对后台耗电限制的名称和入口不同，请按机型对应开启：

- **OPPO / 一加 / realme（ColorOS / realme UI）**：
  - `设置` → `应用` → `应用管理` → `PodTide` → `耗电管理` → 开启 **完全允许后台行为**；
  - 若系统带有“应用速冻”，请前往 `设置` → `电池` → `更多设置` → `应用速冻` 中关闭 PodTide 的自动速冻。
- **vivo / iQOO（OriginOS）**：
  - `设置` → `电池` → `后台耗电管理` → `PodTide` → 选择 **允许后台高耗电**；
  - 在 `应用管理` → `PodTide` → `权限` → `所有权限` 中确认已开启 **后台弹出界面** 与 **关联启动**。
- **小米 / Redmi（HyperOS / MIUI）**：
  - `设置` → `应用设置` → `应用管理` → `PodTide` → `省电策略` → 选择 **无限制**；
  - 在 `应用管理` → `PodTide` → `其他权限` 中开启 **后台弹出界面**、**显示悬浮窗**、**锁屏显示**。
- **荣耀（MagicOS）**：
  - `设置` → `应用` → `应用启动管理` → 找到 `PodTide` 并关闭右侧开关（取消自动管理） → 在弹窗中勾选 **允许后台活动**；
  - `设置` → 搜索 **电池优化** → 切换为 `所有应用` → 找到 `PodTide` 设为 **不允许**。
- **华为（HarmonyOS / EMUI）**：
  - `设置` → `应用和服务` → `应用启动管理` → 找到 `PodTide` 并关闭自动管理 → 在弹窗中勾选 **允许后台活动**；
  - `设置` → 搜索 **电池优化** → 切换为 `所有应用` → 找到 `PodTide` 设为 **不允许**。
- **三星（One UI）**：
  - `设置` → `应用程序` → `PodTide` → `电池` → 选择 **不受限制**；
  - 在 `设置` → `电池与设备维护` → `电池` → `后台使用限制` 中，将 PodTide 加入 **从不休眠的应用**。
- **魅族（Flyme）**：
  - `设置` → `应用` → `应用管理` → `PodTide` → `权限管理` → `后台管理` → 选择 **允许后台运行**。
- **原生 Android（Pixel、Moto、Nothing OS 等）**：
  - `设置` → `应用` → `PodTide` → `应用电池使用量` → 选择 **无限制**。

### 3. 荣耀（MagicOS）/ 华为 等系统的“关联启动”特别说明

- **允许关联启动（荣耀 / 华为 / vivo 等必开）**：在荣耀系统的 `设置` → `应用` → `应用启动管理` 中关闭 PodTide 的“自动管理”后，弹出的三个选项（允许自启动、**允许关联启动**、允许后台活动）中，**必须额外确保勾选“允许关联启动”**（华为、vivo、OPPO 若在权限列表中有“关联启动”也请一并开启）。若未开启“关联启动”，系统会直接拦截蓝牙广播事件与系统伴侣设备服务（CDM）对 PodTide 的后台唤醒。

## 适用设备和安装

- Android 8.0（API 26）及以上；耳机功能取决于型号、固件以及手机蓝牙实现。
- 首台测试设备是 OPPO Find X9 / ColorOS，耳机为 AirPods Pro 3。项目面向其他满足系统要求的 Android 设备，欢迎反馈具体机型与系统版本。
- 推荐通过 [PodTide 专属下载通道（Star 解锁）](https://podtide-download.stormlyd.workers.dev) 或 [GitHub Releases](https://github.com/Stormlyd/PodTide/releases) 获取 APK，传到手机并安装。按系统提示授予位置、附近设备、通知、悬浮窗及其他与所用功能相关的权限。
- 已安装相同签名的 PodTide 开发版可直接覆盖更新。自行编译的 APK 如果签名不同，需要按 Android 的应用安装规则处理。

## 已有功能

- 通过蓝牙广播检测耳机，显示耳机和充电盒电量、连接及佩戴信息；具体可用信息取决于设备广播。
- 在可确认耳机空闲或未被占用时尝试自动连接；另一设备正在使用或状态不明确时不主动抢占。可选择开盖、佩戴等连接条件。
- 对支持的机型切换降噪、通透等聆听模式，并提供耳机设置。AirPods Pro 3 在初始连接和同一副耳机断开重连后的通透／降噪切换，已由首台测试机用户实测正常。
- 底部连接和开盒弹窗、耳机电量小组件、可选手机电量显示，以及戴入／取下等自动反应。顶部状态弹窗已停止使用；耳机已连接时不再单独触发开盒弹窗，以减少重复弹出。
- 通知中的实时耳机电量可以选择开启；关闭时保留后台监测通知，并减少电量变化引起的通知更新。后台检测仍需要蓝牙监听，实际耗电随手机和使用情况变化。
- AirPods Pro 3 心率页面在进入时启动测量，离开或切到后台时停止；显示实时读数、本机历史曲线、平均值和最高值。首台测试机用户确认已能读到心率，其他设备、准确性和长期稳定性仍需验证。
- 支持头部姿态预览与点头／摇头手势控制（来电振铃时点头接听、摇头拒接，以及可选的媒体控制）。
- 提供 Apple 官方“查找”网页入口。该入口由浏览器打开，原生账号登录和位置显示仍在开发中。

## 使用提示

如果更重视连接成功率，可以选择“检测到设备时”；“开盖时”则可以减少关盖时的连接尝试。耳机断开时应用会监听蓝牙广播，匹配的已配置设备都连接且控制通道就绪后停止扫描，断开后恢复。暂停扫描期间，依赖广播的盒盖和佩戴信息可能暂不更新。后台扫描速度及弹窗出现时间可能因手机、电池策略和系统版本而异。

如果后台无电量更新或开盖不重连，请先对照上方《系统适配与必开权限指南》检查位置、附近设备、通知、悬浮窗和自启动权限，再确认系统电池管理已允许 PodTide 后台活动。应用提供“后台运行帮助”入口；厂商专属开关的实际状态需要在系统设置中确认。

## 0.4.0 版本更新说明

- **头部姿态与手势控制**：开放设备设置中的「头部姿态与手势测试」入口与手势设置卡；优化自动零点校准与双侧摇头识别，支持来电振铃时点头接听／摇头拒接，以及可选的连续手势媒体控制（默认关闭以防误触）。
- **双耳续航预测优化**：修复满电或高电量下左右耳预计可用时间偏差过大的问题，收紧单耳历史高功耗异常上限并加入高电量双耳协同收敛。
- **后台常驻通知静默开关**：在「设置 → 常规」中新增「显示后台常驻通知」开关，关闭后常驻通知自动转入静默折叠状态，不在状态栏显示图标。
- **睡眠监测防误触**：增加双耳佩戴校验与多阶段滑动时间窗口确认，避免静坐、看书时偶发误暂停音乐。
- **标准系列连接与系统级唤醒优化**：保持 BLE 扫描直至 AAP 控制通道就绪，打通 AirPods Gen 5 有线／无线充电盒身份匹配，并完善系统级伴侣设备唤醒（CDM）配置。

## 已处理的关键问题

- **后台无法自动连接：** 首台测试机的常驻通知仍在，但系统冻结了应用的后台执行；允许后台活动后，至少30秒后开盖连接的复现测试恢复。各厂商的电池策略需要分别确认。
- **重连后降噪切换无效：** 控制服务发出断开消息后，旧版本仍把通道当作就绪状态。现在会清理旧会话并重新建立控制连接；首台测试机已完成同一副耳机重连后的切换测试。
- **弹窗出现太快：** 入场动画等待内容准备完成后再开始，并放慢入场和退场；系统关闭动画时即时显示。
- **后台刷新较频繁：** 对有自动连接任务的已配对耳机，后台请求均衡扫描；通知中的实时电量改为可选，关闭后不再因电量变化反复更新通知。

## 构建

使用 JDK 21、Android SDK 36、Android SDK Build Tools 36.0.0，设置 `ANDROID_HOME` 或 `local.properties` 后，在项目根目录执行：

```bash
./gradlew testFossDebugUnitTest assembleFossDebug
```

Windows 可使用 `gradlew.bat`。正式发行包使用 `assembleFossRelease`，需要自行配置签名。FOSS 变体没有功能付费墙。
