# PodTide

PodTide 是一款面向 Android 的开源 AirPods 伴侣应用，提供电量显示、连接辅助和耳机控制。应用基于 [CAPod](https://github.com/d4rken-org/capod)，并参考 [LibrePods](https://github.com/librepods-org/librepods) 的协议与功能实现。

> **后台运行提示：请检查手机对 PodTide 的电池和后台活动限制。** 为了在应用位于后台时检测耳机、显示弹窗和尝试自动连接，建议在系统应用设置中允许后台活动。不同品牌和系统的名称、路径可能不同。
>
> 如果手机提供最近任务锁定功能，请在最近任务中锁定 PodTide，减少应用被系统清理的机会；设置名称及效果因品牌而异。
>
> **OPPO / ColorOS 示例：** 系统应用详情 → 耗电管理 → 完全允许后台行为。Find X9 上的初步测试中，允许该选项后曾恢复后台开盖连接。后续仍观察到系统冻结和清理进程；在最近任务中锁定应用后，一次等待至少30秒的测试连接成功，长期稳定性仍需验证。其他 Android 设备请在各自的系统设置中寻找相应选项。

## 适用设备和安装

- Android 8.0（API 26）及以上；耳机功能取决于型号、固件以及手机蓝牙实现。
- 首台测试设备是 OPPO Find X9 / ColorOS，耳机为 AirPods Pro 3。项目面向其他满足系统要求的 Android 设备，欢迎反馈具体机型与系统版本。
- 从 [GitHub Releases](https://github.com/Stormlyd/PodTide/releases) 或 [Gitee 发行版](https://gitee.com/falling-silenceLYD/PodTide/releases) 下载 APK，传到手机并安装。按系统提示授予附近设备、通知及其他与所用功能相关的权限。
- 已安装相同签名的 PodTide 开发版可直接覆盖更新。自行编译的 APK 如果签名不同，需要按 Android 的应用安装规则处理。

## 已有功能

- 通过蓝牙广播检测耳机，显示耳机和充电盒电量、连接及佩戴信息；具体可用信息取决于设备广播。
- 在可确认耳机空闲或未被占用时尝试自动连接；另一设备正在使用或状态不明确时不主动抢占。可选择开盖、佩戴等连接条件。
- 对支持的机型切换降噪、通透等聆听模式，并提供耳机设置。AirPods Pro 3 在初始连接和同一副耳机断开重连后的通透／降噪切换，已由首台测试机用户实测正常。
- 底部连接弹窗与可选顶部状态弹窗、耳机电量小组件、可选手机电量显示，以及戴入／取下等自动反应。
- 通知中的实时耳机电量可以选择开启；关闭时保留后台监测通知，并减少电量变化引起的通知更新。后台检测仍需要蓝牙监听，实际耗电随手机和使用情况变化。
- 提供 Apple 官方“查找”网页入口。该入口由浏览器打开，原生账号登录和位置显示仍在开发中。

## Root 与系统兼容性

PodTide 当前公开版本按免 Root 方式实现。基础电量和广播检测依赖蓝牙权限，部分高级控制是否可用还取决于设备型号、系统版本及蓝牙实现。OPPO Find X9 / ColorOS 已进行免 Root 测试；其他机型和 vivo 的兼容性有待实测。本项目目前没有经过验证的 Root 模式，不能将需要 Root 视为已支持的解决办法。

参考项目 LibrePods 表示 ColorOS / OxygenOS 16、realme UI 7 及特定 Android 16 QPR3 Pixel 设备的大部分功能可免 Root；这是 LibrePods 自身的兼容性资料，并不等同于 PodTide 的实测结果。参见 [LibrePods Android 说明](https://github.com/librepods-org/librepods/blob/main/android/README.md) 和 [CAPod 兼容性追踪](https://github.com/d4rken-org/capod/issues/538)。
## 使用提示

如果更重视连接成功率，可以选择“检测到设备时”；“开盖时”则可以减少关盖时的连接尝试。耳机断开时应用会监听蓝牙广播，匹配的已配置设备都连接后停止扫描，断开后恢复。暂停扫描期间，依赖广播的盒盖和佩戴信息可能暂不更新。后台扫描速度及弹窗出现时间可能因手机、电池策略和系统版本而异。

如果后台无电量更新或开盖不重连，请先检查蓝牙、附近设备和通知权限，再检查系统电池管理是否允许 PodTide 后台活动。应用提供“后台运行帮助”入口；厂商专属开关的实际状态需要在系统设置中确认。

## dev12 已知问题

- 少数情况下耳机已经连接，弹窗仍可能重复出现；后续版本将继续优化。
- 顶部状态弹窗在部分设备上可能影响连接；遇到该问题请保持关闭并使用底部弹窗。
- 心率和头部姿态功能尚未在此测试版中开放。

## 已处理的关键问题

- **后台无法自动连接：** 首台测试机的常驻通知仍在，但系统冻结了应用的后台执行；允许后台活动后，至少30秒后开盖连接的复现测试恢复。各厂商的电池策略需要分别确认。
- **重连后降噪切换无效：** 控制服务发出断开消息后，旧版本仍把通道当作就绪状态。现在会清理旧会话并重新建立控制连接；首台测试机已完成同一副耳机重连后的切换测试。
- **弹窗出现太快：** 入场动画等待内容准备完成后再开始，并放慢入场和退场；系统关闭动画时即时显示。
- **后台刷新较频繁：** 对有自动连接任务的已配对耳机，后台请求均衡扫描；通知中的实时电量改为可选，关闭后不再因电量变化反复更新通知。

## 后续计划

头部姿态与手势、心率读取、原生 Find My 位置显示及双设备同时连接仍在开发或验证中。本版隐藏未完成的传感器入口，保留相关源码供后续继续开发。欢迎通过 Issues 提供机型、Android 版本、耳机型号、复现步骤和经检查的脱敏日志；请勿上传账号密码、验证码或私钥。

## 构建

使用 JDK 21、Android SDK 36、Android SDK Build Tools 36.0.0，设置 `ANDROID_HOME` 或 `local.properties` 后，在项目根目录执行：

```bash
./gradlew testFossDebugUnitTest assembleFossDebug
```

Windows 可使用 `gradlew.bat`。正式发行包使用 `assembleFossRelease`，需要自行配置签名。FOSS 变体没有功能付费墙，不需要 Root 或 Shizuku。
